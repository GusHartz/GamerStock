# GamerStock

GamerStock is a performance-based trading platform for esports players.

The platform allows users to trade shares of esports players based on real competitive performance data.

## Core Concept

Performance creates value.  
The market creates price.

GamerStock combines:

- Esports
- Financial markets
- Gamification

## Core Engines

### Performance Engine
Analyzes match data and calculates player performance scores.

### Fair Value Engine
Calculates the fundamental value of each player based on performance metrics.

### Trading Engine
Users can buy and sell shares of players in a market environment.

### Arena
A gamified trading competition system where users compete based on trading performance.

## Tech Stack
